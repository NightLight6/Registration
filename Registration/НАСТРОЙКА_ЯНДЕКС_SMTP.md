# Настройка Яндекс SMTP для отправки писем

## Важно!
Для работы с Яндекс SMTP необходимо использовать **пароль приложения**, а не основной пароль от аккаунта.

## Шаги настройки:

### 1. Получение пароля приложения Яндекс

1. Перейдите на страницу безопасности Яндекс ID: https://id.yandex.ru/security/app-passwords
2. Войдите в свой аккаунт Яндекс
3. Прокрутите страницу до раздела "Пароли приложений"
4. Нажмите "Создать новый пароль"
5. Выберите название приложения (например, "WPF Registration App")
6. Скопируйте сгенерированный пароль (он будет показан только один раз!)

### 2. Настройка в коде

Откройте файл `Registration/Pages/AuthPage.xaml.cs` и найдите строки:

```csharp
private readonly EmailService _emailService = new EmailService(
    "your-test-email@yandex.ru",  // Замените на ваш email Яндекс
    "your-app-password"            // Замените на пароль приложения Яндекс
);
```

Замените:
- `your-test-email@yandex.ru` на ваш реальный email Яндекс (например, `myname@yandex.ru` или `myname@ya.ru`)
- `your-app-password` на пароль приложения, полученный на шаге 1

### 3. Проверка работы

После настройки:
1. Запустите приложение
2. Попробуйте восстановить пароль (кнопка "Забыли пароль?")
3. Проверьте почту - должно прийти письмо с кодом восстановления

## Параметры SMTP Яндекс:

- **SMTP сервер:** smtp.yandex.ru
- **Порт:** 587
- **SSL/TLS:** Включен (EnableSsl = true)
- **Аутентификация:** Требуется (логин и пароль приложения)

## Возможные проблемы:

### Ошибка "535 Authentication failed"
- Убедитесь, что используете пароль приложения, а не основной пароль
- Проверьте, что email указан правильно

### Ошибка "Unable to connect to the remote server"
- Проверьте интернет-соединение
- Убедитесь, что порт 587 не заблокирован файрволом
- Попробуйте использовать порт 465 с SSL

### Письма не приходят
- Проверьте папку "Спам" в почте
- Убедитесь, что email получателя указан правильно
- Проверьте логи приложения на наличие ошибок
